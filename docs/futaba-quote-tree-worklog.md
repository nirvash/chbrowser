# ふたば引用ツリー 作業ログ

## 指示書から変更した仕様

- 当初の指示書では、ツリーの子レスに含まれる引用ブロックを `<details>` で折りたたみ、必要時に展開する方針だった。
- ユーザー確認により、5ch の `>>246` と同じ操作感へ変更した。
  - 引用を折りたたまず、引用元のレス番号を `>><レス番号>` のリンクとして表示する。
  - リンクへマウスオーバーすると、既存のレス本文ポップアップを表示する。
  - ふたば由来の `>No.246` も同じリンクへ変換する。
- 引用元を一意に解決できない場合は、誤ったレスへリンクしないため、元の引用文を残す。
- 引用深度の解析結果は、表示形式の判定ではなく、ツリーの親子関係の解決にも引き続き使用する。
