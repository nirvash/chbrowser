# ふたば引用ポップアップ追加記録

## 仕様変更

元の指示書では、引用元レスをポップアップで表示する場合、親レス全体を表示する想定だった。

ユーザー要望により、ふたばの引用を置き換えた `>>親レス番号` リンクについては、ポップアップに親レス全体を表示せず、リンク元の子レスが実際に引用していた引用部分だけを表示する仕様へ変更した。

通常本文に元から存在する `>>246` リンクは従来どおり、対象レス全体をポップアップ表示する。

## 実装状況

- ふたば引用リンクへ引用本文を `data-quote-preview` として保持。
- ふたば引用リンク専用ポップアップを追加。
- 通常のレスアンカーポップアップとは表示内容を分岐。
- 引用本文内のレスアンカーはポップアップ連鎖に対応。
- JavaScript構文チェック、Nodeテスト11件、Debugビルド（警告0・エラー0）を確認済み。
- 実スレ上の表示確認はユーザー確認待ち。
